# AI Development Environment Configuration

Portable dotfiles for Claude Code environments. Files are **symlinked** (not copied) so edits in `~/.claude/` flow back to the repo automatically.

## Quick Start

```bash
git clone https://github.com/paulliwali/config-files
cd config-files
chmod +x setup.sh
./setup.sh
```

`setup.sh` is idempotent — re-run at any time to pick up new files. Existing files are backed up with a timestamp before being replaced.

## What Gets Symlinked

### `~/.claude/` (Claude Code config)

| Source | Target | Purpose |
|--------|--------|---------|
| `.claude/settings.json` | `~/.claude/settings.json` | Global permissions, hooks, status line |
| `.claude/CLAUDE*.md` | `~/.claude/CLAUDE*.md` | Coding guidelines & topic files |
| `known_marketplaces.json` | `~/.claude/plugins/known_marketplaces.json` | Plugin marketplace config |
| `plugins/custom-skills/` | `~/.claude/plugins/custom-skills/` | Custom slash commands & skills |

### `~/` (Home directory scripts)

| Source | Target | Purpose |
|--------|--------|---------|
| `discord-notify.sh` | `~/discord-notify.sh` | Hook script for Discord notifications |
| `discord-bridge.py` | `~/discord-bridge.py` | Discord bot for remote session control |
| `claude-session` | `~/claude-session` | Multi-session manager |
| `get-channel-id.py` | `~/get-channel-id.py` | Discord channel ID utility |
| `init-all-sessions.sh` | `~/init-all-sessions.sh` | Auto-start all sessions |

## Settings Architecture

- **`settings.json`** (global, symlinked) — permissions, hooks, status line, plugins. Hooks call `bash ~/discord-notify.sh` without a session name; the script derives it from `$PWD`.
- **`settings.local.json`** (per-repo, generated by `claude-session init-repo`) — overrides hooks with a hardcoded `CLAUDE_SESSION_NAME=<repo>` prefix for multi-session Discord routing.

## Custom Skills Plugin

```
plugins/custom-skills/
  .claude-plugin/plugin.json    # Plugin metadata
  commands/                     # User-invocable slash commands
  skills/                       # Model-invoked skills
```

Add markdown files to `commands/` or `skills/` — see `plugins/custom-skills/README.md` for format details.

## Multi-Session Management

```bash
~/claude-session add            # Interactive wizard to add a repo
~/claude-session init-repo <n>  # Generate per-repo settings.local.json
~/claude-session start <n>      # Start tmux + Discord bot
~/claude-session status         # Quick overview
```

## Updating

Since everything is symlinked, just edit files in place and commit:

```bash
cd ~/config-files   # or wherever you cloned it
git add -A && git commit -m "feat: update settings"
git push
```

Other instances pick up changes with `git pull`.

## Security Note

This repository does **not** contain API keys, tokens, or credentials. Configure those separately after cloning.
